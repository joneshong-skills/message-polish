# Message Polish（訊息潤飾）

一個將草稿訊息優化為專業且溫暖的商業溝通的 Claude Code Skill。保留作者的語氣與意圖，只修正不專業、尷尬或不清楚的部分，並為每項修改附上簡短說明。

## 功能特色

- 三種語調光譜：正式、專業溫暖（預設）、輕鬆專業
- 診斷七類常見問題：被動攻擊語氣、預設對方感受、商業術語/陳腔濫調、話題混雜、過度保守、重複囉嗦、語域不一致
- 輸出可直接複製貼上的潤飾版本，並附上修改批註說明
- 迭代精煉：根據回饋（「太正式」、「還是口語」）調整語調
- 繁體中文商業溝通地雷整理，含具體替換範例
- Session 內偏好追蹤，保持多則訊息的語調一致性

## 使用方式

```
/message-polish
```

觸發詞：貼上草稿並要求潤飾、「幫我潤飾這則訊息」、「改一下這封 email」、「讓這段文字更專業」，或直接貼上草稿內容。

## 運作原理

Skill 從草稿中識別收件人、溝通管道、關係層級與意圖，接著依優先順序掃描語調與清晰度問題。輸出格式為引用區塊的潤飾版本，以及說明「改了什麼、為什麼改」的簡潔批註——而非只說「聽起來比較好」。後續調整在 session 內持續追蹤，確保一致性。
